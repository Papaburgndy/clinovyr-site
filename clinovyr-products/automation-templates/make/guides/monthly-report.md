# Monthly Performance Report

## What it does

Runs on the first of each month, pulls KPI data from the CRM, and emails a summary report to stakeholders.

## Customization per client

- **KPI selection**: Define which metrics to pull (leads, conversions, revenue, appointments booked).
- **Report recipients**: Update the email recipient list for owners, managers, or department heads.
- **Schedule**: Adjust day-of-month and hour to match the client's reporting cadence.
- **Google Sheets**: Optionally append data to a shared spreadsheet for historical tracking.

## How to test after setup

1. Run the scenario once manually (don't wait for the 1st of the month).
2. Confirm CRM metrics are pulled without errors.
3. Verify the email report contains accurate numbers for the test period.
4. Check that all intended recipients receive the report.
5. Review formatting on mobile and desktop email clients.
